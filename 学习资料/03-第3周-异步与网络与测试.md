## 1. asyncio：直接对照协程理解

### 1.1 核心映射表

| Kotlin 协程 | Python asyncio | 说明 |
| --- | --- | --- |
| `suspend fun` | `async def` | 定义挂起函数 |
| 挂起点 | `await` | 只有 async 函数内能 await |
| `runBlocking { }` | `asyncio.run(main())` | 桥接同步世界 → 异步世界 |
| `coroutineScope { }` | `asyncio.TaskGroup` / `asyncio.gather` | 结构化并发 |
| `async/awaitAll` | `asyncio.gather(t1, t2, ...)` | 并发多个任务 |
| `Dispatchers.IO` | `asyncio.to_thread(...)` | 把阻塞操作丢到线程池 |
| `Job.cancel()` | `task.cancel()` | 取消任务 |
| `Mutex` | `asyncio.Lock` | 协程间互斥 |

### 1.2 最小示例

```python
import asyncio

async def fetch(name: str, delay: float) -> str:      # ≈ suspend fun fetch(): String
    await asyncio.sleep(delay)                        # 非阻塞等待 ≈ delay()
    return f"{name} 完成"

async def main() -> None:
    # 串行：总耗时 = delay1 + delay2
    r1 = await fetch("A", 1.0)
    r2 = await fetch("B", 1.0)

    # 并发：总耗时 ≈ max(delay1, delay2)  ≈ Kotlin async/awaitAll
    results = await asyncio.gather(
        fetch("A", 1.0),
        fetch("B", 1.0),
        fetch("C", 1.0),
    )
    print(results)   # ['A 完成', 'B 完成', 'C 完成']，顺序与传入顺序一致

asyncio.run(main())   # ≈ runBlocking { main() }
```

要点：

- `async def` 定义的是**协程对象**，直接调用不会执行！必须 `await` 或交给事件循环（≈ Kotlin 调 suspend 函数必须在协程里）。
- `asyncio.gather` 返回值按**传入顺序**排列，不是完成顺序。
- 3.11 推荐用 `TaskGroup`（结构化并发，一个失败全部取消）：

```python
async def main() -> None:
    async with asyncio.TaskGroup() as tg:
        t1 = tg.create_task(fetch("A", 1.0))
        t2 = tg.create_task(fetch("B", 1.0))
    print(t1.result(), t2.result())
```

### 1.3 事件循环与阻塞 IO（验收必考）

**事件循环（event loop）**：单线程的调度器，维护一个任务队列，谁 `await` 释放控制权就调度谁。所有协程共享这**一个线程**。

**为什么不能在 async 函数里调阻塞 IO**：

```python
async def bad():
    resp = requests.get("https://api.example.com")   # requests 是阻塞库！
    # 这行卡住的不是当前协程，而是整个事件循环——所有其他协程全部停摆
```

正确做法二选一：换异步库（`httpx.AsyncClient`），或丢线程池 `await asyncio.to_thread(blocking_fn)`。

对照 Kotlin：协程里在 `Dispatchers.Default` 上调阻塞 IO 会卡线程池，所以要 `withContext(Dispatchers.IO)`——原理一模一样，只是 Python 的事件循环是**单线程**的，后果更严重（连 CPU 密集任务也会卡住整个循环）。

## 2. httpx：Python 世界的 OkHttp

安装：`uv add httpx python-dotenv`。

```python
import httpx

# 同步用法（≈ OkHttp 同步调用）
with httpx.Client(timeout=10) as client:
    resp = client.get("https://httpbin.org/get", params={"q": "hi"})
    resp.raise_for_status()          # ≈ 检查 HTTP 错误码，非 2xx 抛异常
    data = resp.json()               # ≈ Gson 解析

# 异步用法（Agent 代码主流）
async with httpx.AsyncClient(timeout=10) as client:
    resp = await client.post("https://httpbin.org/post", json={"key": "value"})
    print(resp.status_code, resp.json())
```

常用点：

- `params=`、`json=`、`headers=`、`timeout=` 对应 OkHttp 的 Request.Builder
- `resp.raise_for_status()` 别忘写，否则 4xx/5xx 不抛异常
- **复用 Client**（连接池），不要每请求新建
- 也有 `AsyncClient.stream(...)` 支持流式响应——第 4 周 LLM 流式输出就靠它

## 5. 本周项目实战：并发 API 汇总脚本

需求：并发请求 3 个公开 API，汇总输出，对比串行/并发耗时。

`week03/concurrent_fetch.py`：

```python
"""并发请求多个公开 API 并汇总。运行: uv run python concurrent_fetch.py"""
import asyncio
import time

import httpx

APIS = [
    ("汇率", "https://open.er-api.com/v6/latest/USD"),
    ("IP归属", "https://ipapi.co/json/"),
    ("随机用户", "https://randomuser.me/api/"),
]


async def fetch(client: httpx.AsyncClient, name: str, url: str) -> dict:
    resp = await client.get(url, timeout=10)
    resp.raise_for_status()
    return {"name": name, "data": resp.json()}


def summarize(results: list[dict]) -> str:
    lines = []
    for r in results:
        body = r["data"]
        if "rates" in body:                          # 汇率 API
            lines.append(f"{r['name']}: 1 USD = {body['rates'].get('CNY')} CNY")
        elif "ip" in body:                           # IP API
            lines.append(f"{r['name']}: {body.get('city')} ({body.get('ip')})")
        else:
            lines.append(f"{r['name']}: OK")
    return "\n".join(lines)


async def run(parallel: bool) -> float:
    start = time.perf_counter()
    async with httpx.AsyncClient() as client:
        if parallel:
            results = await asyncio.gather(*(fetch(client, n, u) for n, u in APIS))
        else:
            results = [await fetch(client, n, u) for n, u in APIS]
    print(summarize(results))
    return time.perf_counter() - start


async def main() -> None:
    t1 = await run(parallel=False)
    t2 = await run(parallel=True)
    print(f"\n串行 {t1:.2f}s  vs  并发 {t2:.2f}s")
    assert t2 < t1, "并发应该更快"


if __name__ == "__main__":
    asyncio.run(main())
```
