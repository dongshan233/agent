## 使用方法

1. **先读计划原文**（`../Agent开发学习计划-安卓工程师版.md`）了解本周验收标准，再读本资料。
2. 资料中的代码块都是可运行的骨架，**建议亲手敲一遍而不是复制**——尤其是第 5、6 周。
3. 每周末用资料末尾的「验收自测」逐条打勾，对应计划里的验收标准。
4. 卡住时优先查官方文档，不要囤教程。

## 全局约定

- Python 版本：3.11+，包管理用 `uv`
- 代码仓库：`agent-learning`，目录按周组织：`week01/`、`week02/` ...
- API Key 一律放 `.env`，`.gitignore` 必须包含 `.env`
- 模型平台：接口均以 OpenAI 兼容模式为准（国内百炼/DeepSeek、海外 OpenAI/Anthropic 皆适用）
