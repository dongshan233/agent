# P2-01 A2A 协议最小实现：让 Agent 能发现并委派给 Agent

> P2 协议补全 · 模块 1 / 2。**前置**：P0 四个模块，建议先做 P1-02（分层多 Agent）。
> 目标：把 P1-02 里进程内的 specialist 拆成独立 HTTP 服务，用 A2A 的 Agent Card 发现 + Task 生命周期完成一次跨进程委派。

## 学习目标

1. 理解 2026 年 MCP 与 A2A 的**分层关系**（纵向工具 / 横向协作）
2. 实现最小 Agent Card 发现与 Task 状态机
3. 写一对 A2A Server / Client，跑通「发现 → 委派 → 轮询 → 取结果」
4. 把跨进程调用接进 P0-01 的 trace（父子 trace 跨服务传递）
5. 知道教学最小子集与生产规范的边界，不照抄过时博客

## 1. 为什么（对照安卓 + 2026 生态）

一期第 9 周你学了 MCP：把**工具**从进程内函数变成标准服务。P1-02 里三个 specialist 还在同一个 Python 进程里靠函数调用分派。问题来了：如果 specialist 是别的团队用别的语言、别的框架写的呢？如果它跑在另一台机器上呢？

**MCP 不解决这个问题**——MCP 管的是「Agent ↔ 工具」。Agent 之间互相发现、委派、追踪任务进度，需要另一层协议。

2026 年的分层已经确立：

| 层 | 协议 | 管什么 | 谁 ↔ 谁 |
| --- | --- | --- | --- |
| 横向协作 | **A2A** | Agent 发现、任务委派、Task 生命周期、跨组织协商 | Agent ↔ Agent |
| 纵向连接 | **MCP** | Tool / Resource / Prompt 调用、上下文注入 | Agent ↔ 工具 |

关键时间点（了解即可，避免看错文档）：2026 年 6 月 Linux Foundation 下的 Agentic AI Foundation 发布了 MCP 与 A2A 融合草案，两者形成「同一屋檐下、不同房间」的治理结构——**分层互补，不是互相替代**；同年 7 月 CNCF 把 MCP 确认为主要工具暴露协议、A2A 确认为 Agent 间通信协议。A2A v1.0 引入了签名 Agent Card、多租户等能力。

对照安卓，这套你很熟：

| 安卓 | A2A |
| --- | --- |
| `PackageManager` 查谁能处理这个 Intent | **Agent Card 发现**（这个 Agent 会干什么） |
| `Intent` + action + extras | Task 请求 + 消息部件 |
| 绑定 Service 后异步回调 | 提交 Task → 轮询/流式取结果 |
| `ServiceConnection` 的生命周期 | Task 状态机（submitted → working → completed） |
| 签名权限 / `android:permission` | Signed Agent Card / 鉴权令牌 |
| 跨进程调用链 trace | 跨服务 `parent_trace_id` 透传 |

> **规范边界（重要）**：本模块用「HTTP + JSON 的教学最小子集」演示**原理**——概念与官方对齐（Agent Card、Task、状态机、委派），但传输和方法名做了最简化，方便你用 curl 调试。**生产请用官方 A2A SDK 与当前规范**（JSON-RPC 方法、Signed Agent Card、流式事件等），不要把这个最小实现当成协议实现。

## 2. 概念：Agent Card 与 Task 状态机

**Agent Card** 是一个 Agent 的「自我介绍」，放在约定路径供发现：

```json
{
  "name": "weather-specialist",
  "description": "天气与温度查询专员，只处理天气相关问题",
  "url": "http://127.0.0.1:9001",
  "version": "2.0.0",
  "skills": [
    {"id": "weather.query", "name": "天气查询",
     "description": "查询指定城市当前气温并给出穿衣建议",
     "examples": ["苏州今天穿什么", "上海和北京谁更冷"]}
  ],
  "capabilities": {"streaming": false, "pushNotifications": false},
  "auth": {"schemes": ["bearer"], "required": true}
}
```

**Task 状态机**（官方概念的简化版）：

```
        POST /a2a/tasks/send
              │
              ▼
        submitted ──→ working ──→ completed
                         │
                         ├──→ failed          （专员执行出错）
                         └──→ input-required  （需要人工确认，接一期 interrupt）
```

| 状态 | 含义 | 本模块 |
| --- | --- | --- |
| `submitted` | 已受理，尚未开始 | ✅ |
| `working` | 正在执行 | ✅ |
| `completed` | 成功，结果在 `result` | ✅ |
| `failed` | 失败，原因在 `error` | ✅ |
| `input-required` | 等人确认（对齐一期第 8 周 interrupt） | 讲概念，P2-02 接 |

**为什么要有状态机而不是同步 HTTP 等结果**：Agent 任务可能跑几十秒甚至等人确认十分钟。同步请求会超时、连接断了结果就丢。Task id + 轮询是「可恢复的异步调用」——对照安卓：绑定 Service 后拿一个 token，稍后回调取结果。一期第 8 周的 `thread_id` + Checkpointer 是同一个思路。

### 步骤 2：`server/a2a/models.py`

```python
"""server/a2a/models.py —— A2A 教学最小子集的模型。"""
from __future__ import annotations

from datetime import datetime
from enum import Enum
from typing import Any

from pydantic import BaseModel, Field


class TaskStatus(str, Enum):
    SUBMITTED = "submitted"
    WORKING = "working"
    COMPLETED = "completed"
    FAILED = "failed"
    INPUT_REQUIRED = "input-required"


class AgentSkill(BaseModel):
    id: str
    name: str
    description: str
    examples: list[str] = Field(default_factory=list)


class AgentCard(BaseModel):
    name: str
    description: str
    url: str
    version: str
    skills: list[AgentSkill]
    capabilities: dict[str, bool] = Field(default_factory=dict)
    auth: dict[str, Any] = Field(default_factory=dict)


class SendRequest(BaseModel):
    """对齐官方「tasks/send」语义：带一条消息与可选元数据。"""
    message: str
    metadata: dict[str, Any] = Field(default_factory=dict)


class A2ATask(BaseModel):
    id: str
    status: TaskStatus
    message: str
    result: dict[str, Any] | None = None
    error: str | None = None
    created_at: str = Field(default_factory=lambda: datetime.now().isoformat(timespec="seconds"))
    updated_at: str = Field(default_factory=lambda: datetime.now().isoformat(timespec="seconds"))
    parent_trace_id: str = ""


def touch(task: A2ATask, status: TaskStatus, **kw: Any) -> None:
    task.status = status
    task.updated_at = datetime.now().isoformat(timespec="seconds")
    for k, v in kw.items():
        setattr(task, k, v)
```

### 步骤 3：`server/a2a/specialist_server.py`（独立进程）

```python
"""server/a2a/specialist_server.py —— 一个可被发现的 Specialist Agent。
启动: uv run uvicorn server.a2a.specialist_server:app --port 9001
"""
from __future__ import annotations

import asyncio
import os
import uuid

from dotenv import load_dotenv
from fastapi import FastAPI, Header, HTTPException

from server.a2a.models import (AgentCard, AgentSkill, A2ATask, SendRequest,
                               TaskStatus, touch)

load_dotenv()
TOKEN = os.getenv("A2A_TOKEN", "dev-only-change-me")
PORT = int(os.getenv("A2A_PORT", "9001"))
BASE = os.getenv("A2A_BASE_URL", f"http://127.0.0.1:{PORT}")

app = FastAPI(title="A2A weather specialist")

CARD = AgentCard(
    name="weather-specialist",
    description="天气与温度查询专员，只处理天气与简单温度换算相关问题。",
    url=BASE,
    version="2.0.0",
    skills=[AgentSkill(
        id="weather.query",
        name="天气查询",
        description="查询指定城市当前气温并给出穿衣建议；可做简单温度换算。",
        examples=["苏州今天穿什么", "上海和北京谁更冷", "18度是多少华氏度"],
    )],
    capabilities={"streaming": False, "pushNotifications": False},
    auth={"schemes": ["bearer"], "required": True},
)

TASKS: dict[str, A2ATask] = {}


def require_token(x_a2a_token: str | None) -> None:
    if TOKEN and x_a2a_token != TOKEN:
        raise HTTPException(status_code=401, detail="invalid A2A token")


@app.get("/.well-known/agent-card.json")
async def agent_card() -> dict:
    """Agent 发现入口。生产里这里应是签名过的 Card。"""
    return CARD.model_dump(mode="json")


@app.get("/health")
async def health() -> dict:
    return {"status": "ok", "name": CARD.name, "version": CARD.version,
            "tasks": len(TASKS)}


@app.post("/a2a/tasks/send")
async def send(req: SendRequest,
               x_a2a_token: str | None = Header(default=None)) -> A2ATask:
    """委派一个任务。立即返回 submitted，后台异步执行。"""
    require_token(x_a2a_token)
    tid = uuid.uuid4().hex
    task = A2ATask(
        id=tid, status=TaskStatus.SUBMITTED, message=req.message,
        parent_trace_id=req.metadata.get("parent_trace_id", ""),
    )
    TASKS[tid] = task
    asyncio.create_task(_execute(tid, req))
    return task


@app.get("/a2a/tasks/{task_id}")
async def get_task(task_id: str,
                   x_a2a_token: str | None = Header(default=None)) -> A2ATask:
    require_token(x_a2a_token)
    if task_id not in TASKS:
        raise HTTPException(status_code=404, detail="task not found")
    return TASKS[task_id]


async def _execute(tid: str, req: SendRequest) -> None:
    """后台执行：接 P1-02 的 specialist，并把 trace 串起来。"""
    task = TASKS[tid]
    touch(task, TaskStatus.WORKING)
    try:
        # ▼ 若你做了 P1-02，用这一行：
        from server.multi.specialists import run_specialist
        reply = await run_specialist(
            "weather", req.message,
            parent_trace_id=task.parent_trace_id or tid,
        )
        # ▼ 若没做 P1-02，把上面两行换成下面这段（自包含回退）：
        # from scripts.demo_tools import TOOL_FUNCS, build_tools
        # from server.base import run_task
        # r = await run_task(req.message, tools=build_tools(), tool_funcs=TOOL_FUNCS)
        # reply = {"ok": not bool(r.error), "answer": r.answer,
        #          "tokens": r.usage.get("total_tokens", 0),
        #          "trace_id": task.parent_trace_id}
        if reply.get("ok"):
            touch(task, TaskStatus.COMPLETED, result=reply)
        else:
            touch(task, TaskStatus.FAILED, result=reply,
                  error=str(reply.get("error") or "specialist failed"))
    except Exception as e:
        touch(task, TaskStatus.FAILED,
              error=f"{type(e).__name__}: {e}")
```

**三个关键点**：

1. **立即返回 + 后台执行**：`asyncio.create_task(_execute(...))` 让 HTTP 请求不被长任务拖住，客户端拿 `task.id` 去轮询。
2. **状态用 `touch()` 原子更新**，同时刷新 `updated_at`——排障时能回答「它卡在 working 多久了」。
3. **`parent_trace_id` 跨进程透传**：客户端在 `metadata` 里带上自己的 trace_id，specialist 的 `run_specialist` 把它写进 root span 的 attributes。于是 P0-01 的 `eval/view_trace.py` 能把「服务端 trace」和「专员 trace」对上，跨服务调用链不再断。

### 步骤 4：`server/a2a/client.py`

```python
"""server/a2a/client.py —— 最小 A2A 客户端：发现 → 委派 → 轮询。"""
from __future__ import annotations

import asyncio
import os

import httpx
from dotenv import load_dotenv

load_dotenv()
TOKEN = os.getenv("A2A_TOKEN", "dev-only-change-me")


def _headers() -> dict:
    return {"X-A2A-Token": TOKEN}


async def discover(base: str) -> dict:
    """GET /.well-known/agent-card.json —— 先发现能力，再决定委派给谁。"""
    async with httpx.AsyncClient(timeout=10) as c:
        r = await c.get(f"{base}/.well-known/agent-card.json")
        r.raise_for_status()
        return r.json()


async def send_task(base: str, text: str,
                    *, parent_trace_id: str = "") -> str:
    async with httpx.AsyncClient(timeout=10) as c:
        r = await c.post(
            f"{base}/a2a/tasks/send",
            headers=_headers(),
            json={"message": text,
                  "metadata": {"parent_trace_id": parent_trace_id}},
        )
        r.raise_for_status()
        return r.json()["id"]


async def get_task(base: str, tid: str) -> dict:
    async with httpx.AsyncClient(timeout=10) as c:
        r = await c.get(f"{base}/a2a/tasks/{tid}", headers=_headers())
        r.raise_for_status()
        return r.json()


async def delegate(base: str, text: str, *, parent_trace_id: str = "",
                   timeout: float = 40.0, interval: float = 0.5) -> dict:
    """完整链路：发现 → 委派 → 轮询到终态。"""
    card = await discover(base)
    print(f"[discover] {card['name']} v{card['version']} "
          f"skills={[s['id'] for s in card['skills']]}")
    tid = await send_task(base, text, parent_trace_id=parent_trace_id)
    print(f"[send] task={tid[:8]} status=submitted")

    waited = 0.0
    while waited < timeout:
        t = await get_task(base, tid)
        if t["status"] in ("completed", "failed", "input-required"):
            print(f"[poll] status={t['status']} after {waited:.1f}s")
            return t
        await asyncio.sleep(interval)
        waited += interval
    raise TimeoutError(f"task {tid} 在 {timeout}s 内未到终态")
```

> `discover()` 这一步别省。真实 A2A 的价值就是**先发现能力再委派**：Orchestrator 读 Agent Card 的 `skills`，决定把子任务交给谁，而不是在代码里硬编码 URL 和能力。P2-02 会把它做成真正的路由。

### 步骤 6：把委派接进 supervisor（改 P1-02 一处）

`server/multi/specialists.py` 里加一个「远程 specialist」，和本地专员实现同一个接口：

```python
# server/multi/remote_specialist.py
import os
from server.a2a.client import delegate
from dotenv import load_dotenv

load_dotenv()
BASE = os.getenv("A2A_BASE_URL", "http://127.0.0.1:9001")


async def run_remote_weather(subtask: str, *, parent_trace_id: str = "") -> dict:
    t = await delegate(BASE, subtask, parent_trace_id=parent_trace_id)
    result = t.get("result") or {}
    return {
        "specialist": "weather", "ok": t["status"] == "completed",
        "answer": result.get("answer", ""),
        "tokens": result.get("tokens", 0),
        "trace_id": result.get("trace_id", ""),
        "error": t.get("error"),
        "transport": "a2a",            # 与本地专员区分，便于 trace 统计
    }
```

把 `supervisor.py` 的 `build_dispatch_funcs()` 里 weather 那一项换成 `run_remote_weather`（签名保持 `async def dispatch(**kwargs)`）。**其余 specialist 不动** —— 这就是分层的价值：一个专员是本地进程还是远程服务，对 supervisor 透明。

### 步骤 7：规范对照表（写进 README）

| 本模块教学版 | 生产 A2A v1.0 | 差异原因 |
| --- | --- | --- |
| REST 路径 `/a2a/tasks/send` | JSON-RPC 方法 `tasks/send` / `tasks/get` | 教学版便于 curl 调试 |
| 内存 `TASKS` dict | 持久化 Task store | 教学版不重启 |
| 客户端轮询 | 流式事件 / 推送通知 | 教学版省复杂度 |
| 共享 `X-A2A-Token` | Signed Agent Card（验证发布者） | 生产需身份验证 |
| 单租户 | 多租户 / 委托链信任 | 生产需跨组织信任模型 |
| Agent Card 无签名 | 签名 + Agent Card 发现 | 生产需防冒名 |

**判断教程新旧的最快方法**（和第 9 周 MCP 一样）：看它是否把 MCP 和 A2A 说成「二选一」。说是替代关系的，基本是 2025 年及以前的旧文；2026 年的共识是分层互补。

## 4. 常见报错与修复

| 现象 | 原因 | 修复 |
| --- | --- | --- |
| `401 invalid A2A token` | 两端 `A2A_TOKEN` 不一致 / Header 名不对 | 确认 `.env` 与 `X-A2A-Token` 完全对应；服务端用 `Header(default=None)` 会自动映射下划线 |
| `Connection refused` | 终端 1 没起 / 端口不对 | `uv run uvicorn ... --port 9001`；检查 `A2A_BASE_URL` |
| Task 永远 `working` | `_execute` 抛异常但没进 except，或模型超时 | 看服务端日志；`touch(task, FAILED)` 在 except 里已兜住；给 httpx 设 timeout |
| `TimeoutError` | 轮询超时太短 | `delegate(..., timeout=60)`；或在服务端给模型调用设更短超时 |
| `ValidationError: status` | 返回了 Enum 而非字符串 | `AgentCard.model_dump(mode="json")` / pydantic v2 的 `model_dump` 已处理 |
| 跨进程 trace 对不上 | `parent_trace_id` 没透传 | `send_task` 的 `metadata` 带上；`_execute` 读 `task.parent_trace_id` |
| 服务端重启后 Task 404 | 内存存储 | 教学版预期行为；生产换持久化 store |
| Agent Card 里 `url` 写死 localhost | 部署到容器后不可达 | 用环境变量 `A2A_BASE_URL` 注入服务名（P2-02 的 compose 里会做） |
| 把 MCP 和 A2A 混成一个协议 | 概念没分层 | 记住：MCP = Agent↔工具（纵向），A2A = Agent↔Agent（横向） |
